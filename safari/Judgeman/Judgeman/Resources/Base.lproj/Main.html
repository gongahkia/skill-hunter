Judgeman for Safari

Readable ELIT judgments with local structured export

This app enables the Judgeman Safari web extension and explains exactly what the shipped build does.

How to enable it

  1. Click the button below to open Safari Settings.
  2. Open the Extensions section.
  3. Enable Judgeman.
  4. Visit a public ELIT judgment under /gd/ or /gdviewer/.

What this release does

  • Shows a compact launcher on supported ELIT judgment pages.
  • Opens a non-destructive reader overlay for the current judgment.
  • Extracts case metadata and judgment sections locally.
  • Copies structured case JSON only when the user clicks the export action.

Privacy and support

The shipped store-safe build does not send judgment content to third-party services and does not store API keys.
